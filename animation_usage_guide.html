Animation Usage Guide

How to use the 5 shortlisted animations mindfully — when to use them, when NOT to use them, and why each one matters.

Principles for Mindful Animation Use

1. Purpose First

Every animation must answer: "Why is this here?" If you can't answer that clearly, don't animate it.

2. Respect Focus

Practice requires concentration. Animations support practice, never interrupt it. No auto-playing, no continuous loops during active work.

3. One Thing at a Time

Max 2 animations on screen simultaneously (e.g., recording pulse + progress bar is OK, but not more). Prevents overwhelm.

4. Celebrate, Don't Distract

Use animations for milestones and achievements. Don't animate every micro-interaction. Reserve motion for moments that matter.

5. Accessibility Always

Respect prefers-reduced-motion. Provide instant, non-animated fallback. No information should be hidden until animation completes.

6. Timing Matters

300–800ms range (responsive, not sluggish). Never faster than 200ms (feels snappy, wrong tone). Never slower than 1s (unless intentional loop).

Animation Usage Matrix

Animation When to Use ✓ When NOT to Use ✕ Frequency
Recording Pulse While recording is actively running. Gives clear "I'm listening" feedback. When paused, stopped, or before recording starts. Don't animate a static state. Once per session (while recording)
Progress Fill Every screen transition (0→33→66→100%). Shows forward momentum consistently. During active practice/recording. Don't distract from the actual work. 5–6 times per session (once per major screen)
Focus Glow Tip cards, hints, educational guidance. Gentle "pay attention to this" signal. Primary CTAs (buttons already have focus). Regular content (only special, hint-like content). 2–3 times per session max (reserve for real hints)
Pulse Success Success screens, problem-solved moments, real achievements. Celebrate milestones. Small interactions or button clicks. Only for meaningful accomplishments, not everything. 1–2 times per session (genuine achievements)
Stagger Entrance Option lists (focus selection, strategy steps). Organizes info thoughtfully without dumping. Single items (no point staggering one thing). Error messages or negative feedback lists. 3–4 times per session (one per list)

Recording Pulse

1.2s loop • Active recording state

Use When
  • Recording is actively running
  • Capturing practice performance
  • Giving user clear feedback: "I'm listening"
Don't Use When
  • Recording is paused or stopped
  • Before user hits record button
  • In sections where practice doesn't happen
Implementation
Apply to record button center. Pulse dot + expanding ring simultaneously.
recordingState === 'active' → start pulse recordingState !== 'active' → remove pulse

Progress Fill

2s ease-out • Session progress

Use When
  • User enters new screen (33%→66%→100%)
  • Moving through practice session steps
  • Showing continuous forward momentum
Don't Use When
  • During active recording (don't distract)
  • Jump bar abruptly (always animate)
  • User is in focused practice mode
Implementation
At top of every screen. Animates 0→33→66→100% as user progresses.
animate progress: currentWidth → targetWidth (2s)

Focus Glow

2s loop • Gentle attention

Use When
  • Tip cards appear ("Did you know?")
  • Educational hints on problem-solving
  • Important guidance needs soft attention
Don't Use When
  • Primary buttons or CTAs (they're already clear)
  • Regular content (only hints/tips)
  • Every card at once (focus = sparse, intentional)
Implementation
Soft terracotta glow expands and fades. Remove after user dismisses tip.
class="tip-card" → apply focusGlow animation

Pulse Success

1s once • Achievement celebration

Use When
  • Success screen appears ("Great work!")
  • Problem is solved and confirmed
  • Real, meaningful milestone reached
Don't Use When
  • Small interactions or button clicks
  • Every minor accomplishment (reserve for big wins)
  • During active practice (only at completion)
Implementation
Checkmark grows from center. Ring expands and fades. One-time, not looped.
successState === true → trigger pulse once

Stagger Entrance

400ms + 100ms delay • List reveal

Use When
  • Focus selection options appear
  • Strategy steps or list of choices
  • 3–5 items that need sequential reveal
Don't Use When
  • Single items (no stagger needed)
  • More than 5 items (adjust timing or split)
  • Error messages or negative lists
Implementation
Each item slides from left. 100ms delay between items. Creates organized reveal.
animation-delay: [index * 100]ms per item

Motion Budget Example: One Practice Session

Here's how many times each animation should appear in a typical practice session:

Animation Expected Uses Total Animation Time
Recording Pulse 1× (during recording, ~2 min) 120 seconds looped
Progress Fill 5–6× (per screen transition) 10–12 seconds total (2s × 5–6)
Focus Glow 2–3× (tip cards) 4–6 seconds (shown, not counted)
Pulse Success 1–2× (big wins) 1–2 seconds total (1s × 1–2)
Stagger Entrance 3–4× (lists) 1.2–1.6 seconds total (400ms × 3–4)

Total active animation time per session: ~15–20 seconds of visible motion (excluding recording pulse loop, which happens in background). This is intentional and sparse — motion doesn't dominate the experience, but it's present when it matters.

Key Takeaway: Motion with Purpose

The 5 animations are not decorative. Each one serves a specific emotional or functional purpose in the Practice Coach experience:

  • ✓ Recording Pulse = "I'm present and listening to your effort"
  • ✓ Progress Fill = "You're moving forward through this session"
  • ✓ Focus Glow = "Here's something useful, no pressure"
  • ✓ Pulse Success = "You achieved something real — celebrate it"
  • ✓ Stagger Entrance = "Here are your options, take your time"

Use them mindfully. Respect user focus. Let motion support practice, never distract from it.
